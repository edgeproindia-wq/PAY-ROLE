Import into Tally Prime
  1. Download Tally: ledgers (XML) and import it first: Import Data → Masters. Ledgers that already exist are reported by Tally and left as they are.
  2. Download Tally: vouchers (XML) and import it: Import Data → Vouchers. Each posted journal becomes one Journal voucher.
  3. The vouchers use the ledger names from General Ledger Mapping. Set those names first, and try the import in a test company before the real one.
